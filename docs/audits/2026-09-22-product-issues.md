# CloudCrane Product Issues — 2026-09-22

以下条目是产品策略或体验取舍，不在没有 Owner 决策时擅自实现；它们不计入工程 Bug 数量。

## PRODUCT-001 Preview 分享有效期与撤销策略

- 场景：用户将预览链接分享给领导或客户，短期 Token 可能在对方查看前过期。
- 当前行为：预览访问依赖带有效期的 Token。
- 方案 A：保留短期 Token，强调临时预览与安全性。
- 方案 B：增加可撤销的长期分享链接，独立于内部预览 Token，并提供失效/重新生成。
- 需要决定：分享链接默认有效期、是否允许匿名访问、是否允许多次生成。

## PRODUCT-002 模型能力与图片附件支持

- 场景：当前模型可能不支持图片附件。
- 方案 A：继续允许上传，发送时给出能力提示。
- 方案 B：在上传前根据当前模型能力禁用或提示，并规划模型切换。
- 需要决定：是否支持模型切换，以及不支持图片时是否允许附件仅作为文件保存。

## PRODUCT-003 网站删除后的恢复与保留期

- 场景：删除网站会清理 Workspace、预览、代码和附件。
- 方案 A：立即删除，降低存储成本。
- 方案 B：进入回收站并保留一段时间后再物理清理。
- 需要决定：是否提供恢复、保留多久、是否计入网站数量和存储配额。

## PRODUCT-004 网站创建失败的清理边界

- 场景：名称创建、Workspace 启动、授权码配置、模板导入可能在不同阶段失败。
- 方案 A：基础创建失败自动清理，授权失败保留网站等待补录授权码。
- 方案 B：所有失败都保留为可重试草稿。
- 需要决定：各状态的用户可见性、重试入口和配额占用规则。

## PRODUCT-005 Preview 刷新策略

- 场景：Agent 修改文件时，逐次刷新会造成预览闪动，不刷新又可能让用户看到旧内容。
- 方案 A：每次修改操作刷新。
- 方案 B：Agent 回合结束统一刷新，必要时允许显式刷新。
- 方案 C：按文件类型/修改批次做去抖刷新。
- 需要决定：刷新延迟、用户手动刷新优先级，以及 Agent 是否需要声明刷新意图。
