# CloudCrane E2E 测试登录说明

本文只说明如何查找和使用测试登录信息，不保存账号或凭据，也不证明账号当前可用。

## 凭据位置

本机私密文件准确路径：

```text
docs/testing/cloudcrane-e2e-test-account.local.md
```

仓库根目录 `.gitignore` 忽略此文件，因此它不会提交到 Git。当前开发工作区可能有该文件；新电脑或 CI 环境不一定有。不要查找通用的 `.local.md` 文件名，也不要将账号标识、密码、Cookie、Token 或认证流程数据写入跟踪文档、日志或提交。

可用以下命令检查文件是否存在，不必先输出文件内容：

```powershell
Test-Path docs/testing/cloudcrane-e2e-test-account.local.md
```

## 使用规则

- 执行 CloudCrane 用户流程 E2E 前，按仓库 `AGENTS.md` 使用 ECS 完整服务栈和指定的验收工具，不用裸启动的本地 Web 端口替代默认验收链路。
- 只在本机私密文件标注的目标站点使用测试账号；不要把它当作生产 CMS 或其他系统的账号。
- 只有在目标站点与账号用途匹配时才登录。报告仅记录验收状态，不回显认证信息。
- 如果文件不存在、凭据过期或目标环境不匹配，不要猜测、扫描其他秘密文件或要求用户把密码发到聊天。请项目负责人在浏览器里自行登录，再继续登录后的验收；凭据需要更新时由负责人直接更新本机私密文件。
